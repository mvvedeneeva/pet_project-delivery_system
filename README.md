# Пет проект | Система курьерской доставки
Учебный проект, направленный на разработку системы курьерской доставки. Предполагается платформа для персонала (оператор, диспетчер) и приложение для курьеров. В репозиторий включены результаты без исходных условий или контекста для сохранения конфиденциальности информации.
 
Результаты работы разбиты по темам и кратко описаны, прикреплена ссылка на соответствующий документ. Где необходимо, подкреплены 2 формата: PDF и исходный редактируемый (xlsx, docx). Таким образом, все документы можно просмотреть, не скачивая репозиторий. 

Цель проекта — создать систему курьеровской доставки, чтобы минимизировать ручной труд оператора по созданию карточек заказа, создать централизованную систему с учетом прошлых заказов, расширить клиентскую базу.
